# Support

Lance is a community project maintained by one person. Thanks for helping keep
questions and reports useful for everyone.

## Where to get help

- **Setup or build problems:** [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) and
  `npm run doctor`. Then search [existing issues](https://github.com/jdcua/Lance/issues).
- **Bug reports:** open an issue with the [bug template](https://github.com/jdcua/Lance/issues/new/choose).
  Include your OS, Lance version, reproduction steps and what you expected.
- **Feature ideas:** open an issue with the feature template, or add to
  [docs/ROADMAP.md](docs/ROADMAP.md).
- **Security vulnerabilities:** do **not** open a public issue. Use the
  [private advisory form](https://github.com/jdcua/Lance/security/advisories/new)
  and follow [SECURITY.md](SECURITY.md).
- **Code of Conduct concerns:** use the private reporting form with "Code of
  Conduct" in the title, as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## What is out of scope

- Paid support, SLAs, or guaranteed response times. We aim to acknowledge
  issues within a few days, but this is a best effort.
- Help with modified or forked builds.
- Data recovery from a corrupted local SQLite database. Back up your data via
  the app's built-in export before experimenting.
- Questions about commercial licensing: Lance is MIT licensed, so no license
  key or support contract is required.

## Before you ask

Run `npm run doctor` and `npm run verify`, read the error message, and include
the exact command output in your report. That solves most setup questions.
