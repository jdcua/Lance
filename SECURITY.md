# Security policy

Lance stores all business data on the user's machine and has no accounts or
server-side data store. The full local-first threat model and mitigations are
in [docs/SECURITY.md](docs/SECURITY.md).

## Reporting a vulnerability

Please report vulnerabilities privately via
[GitHub security advisories](https://github.com/jdcua/Lance/security/advisories/new).
Include the affected version, a reproduction, and the impact. Do not open a
public issue for an unpatched vulnerability.

We aim to acknowledge reports within 48 hours and to publish a fix or a
mitigation before disclosure.

## Supported versions

Only the latest tagged release is supported with security fixes.
