## 1. Retainer intake automation (the meta play)

Problem: $49/mo retainers only work if each change request costs minutes, not hours of back-and-forth.

System: client texts/emails what they want changed (words, photos, design inspo,
"i want it like xyz") → intake rules parse it into a structured change ticket
→ change gets applied → preview sent back automatically.

- Client-facing rules: "text or email changes anytime; include photos + an example link if you have one."
- Internal pipeline: classify (text swap / photo / new section / out-of-scope) → apply → screenshot preview → reply with before/after.
- Out-of-scope auto-detect → converts to a quote instead of silently expanding.

Why it matters: this is the difference between retainers as passive income and
retainers as 10 needy bosses. Automate the intake and one person can hold
30+ retainer clients.
